# SciProof Local MVP

## Цель

Первая версия сервиса должна решать две практические задачи:

1. Review и корректировка крупных научных и деловых текстов.
2. Проверка конкретного факта, тезиса или утверждения.

## Что входит в локальный MVP

- FastAPI backend.
- React + Vite frontend.
- 4 агента + судья.
- Режимы `review_text` и `fact_check`.
- Цикл уточнения контекста:
  - агенты задают вопросы;
  - пользователь отвечает;
  - процесс продолжается.
- Итоговый исправленный текст с пояснениями.
- Фактчекинг с web search как опцией.
- In-memory хранение на старте.
- Интеграционные тесты через полный backend pipeline.

## Что не входит в первую локальную версию

- PostgreSQL и история сессий.
- Экспорт в PDF/Markdown.
- Авторизация.
- Развёртывание на сервере.
- Сложные настройки состава агентов в UI.
- Потоковый SSE-интерфейс.

## Дефолтное поведение

- Тип текста: научный или деловой.
- Размер текста: 3 000–4 000 знаков.
- По умолчанию сохраняется стиль автора.
- Глубокая перестройка текста только по запросу.
- При нехватке контекста сервис сначала задаёт вопросы, а не делает вид, что всё понял.
- При наличии спорных утверждений фактчекинг желателен.

## Следующий шаг реализации

Сначала собрать локальное ядро:
- модели данных;
- prompt builder;
- parser;
- orchestrator;
- judge;
- API для запуска review/fact-check сессии.

После этого — простой UI для ввода текста, ответов на уточняющие вопросы и просмотра итоговой редакции.
